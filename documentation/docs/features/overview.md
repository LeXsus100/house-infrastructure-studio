# Overview

<div class="his-page-lead">
  <span class="his-section-id">FEATURE 03</span>
  <p>Overview converts the active project snapshot into a whole-house technical report. Its totals and filters update from the same walls, rooms, devices, routes, measurements, and installation states used by the editor.</p>
</div>

Open **Overview** beside the project title. The page keeps reports separate from
model editing, which makes it useful during design reviews and before producing
field documents.

## OVERVIEW 01 · Project totals

The summary cards report:

- floor, room, and wall counts;
- total modelled wall length;
- technical-device count and installed or tested count;
- route count and total geometric length;
- routes with a recorded test state;
- visible measurements;
- finished drywall-lining area.

These values are derived at display time from the local project. A saved export
or screenshot represents the project state at the time it was created.

## OVERVIEW 02 · Service and route distribution

The service chart combines device count, route count, and total route length for
each populated technical category. Selecting a service filters the detailed
inventory below.

The route-type cards divide total length into cable, pipe, and duct records. A
second report groups rooms, devices, and route length by floor, including each
floor elevation.

## OVERVIEW 03 · Rooms and zones

**Rooms & zones** presents the house organization independently of the 3D
camera. Each room card includes its category, floor, area, wall count, device
count, route count, and a short device list. Room categories can be created,
edited, or removed from this area.

This view is useful for reviewing spaces with a shared purpose, for example
living spaces, technical rooms, wet rooms, circulation, or exterior areas.

## OVERVIEW 04 · Filtered asset inventory

**Asset inventory** lists devices and routes with four filters:

| Filter | Available choices |
| --- | --- |
| Asset | Devices and routes, devices only, or routes only. |
| Service category | All populated services or one selected service. |
| Status | All, planned, installed, or tested. |
| Floor | Every floor or one selected floor. |

Device rows show the catalogue type, floor, and installation status. Route rows
show subtype or kind, test status, geometric length, and installation status.
Use these filters before a site visit to prepare a focused list of the assets
that need installation, testing, or verification.

## Suggested review sequence

1. Check the house, wall, device, and route totals for obvious omissions.
2. Compare service lengths and route-type totals with the intended design.
3. Review inventory by floor and installation status.
4. Open Rooms & zones to confirm room assignments.
5. Return to the editor for corrections, then reopen Overview to verify them.

Project health checks live under [Settings](settings.md), while printable output
is covered in [Exports and field output](exports.md).
