# Get started

House Infrastructure Studio is local software. Choose the Windows desktop
edition when you want an installed application, or run the browser/server
edition when developing and evaluating the source.

## Before you begin

Plan where you will keep two different things:

- **Source code and installers** can be downloaded again.
- **House project data** can contain irreplaceable measurements, blueprints,
  route metadata, and photographs. Back it up deliberately.

Project work stays on the local computer. The first launch asks for a project
name and creates an empty ground floor. House Infrastructure Studio is a
focused residential documentation tool, designed for practical home-scale
records and clear technical review.

## Pick a route

=== "Windows desktop"

    Download the installer from a trusted project release, verify its checksum,
    and install it for the current Windows user. The bundled Node.js runtime
    supports installed project work with the computer offline.

=== "Run from source"

    Install Node.js 24+ and npm 11+, clone the repository, run `npm install`,
    then start the local React and Express development processes with
    `npm run dev`.

=== "Contribute"

    Follow the source setup, run the full test suite, read the architecture and
    database boundaries, and keep private house data out of commits and issues.
