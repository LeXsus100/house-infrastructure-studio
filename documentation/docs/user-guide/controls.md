# Keyboard and mouse controls

## Viewport

| Input | Action |
| --- | --- |
| Right mouse drag | Orbit the camera; right-button release completes the camera gesture. |
| Middle mouse drag | Pan. |
| Mouse wheel | Zoom; hold `Shift` for fast zoom. |
| Left click | Select, place, or add a control point for the active tool. In Normal view this is the wall-selection button. |
| Ctrl + left click | Add another object of the same type to the selection. |
| Double-click | Finish a room boundary. Routes finish by clicking their destination device. |
| Top toolbar Views | Top (true plan-view orthographic), isometric, fit full house, and fit selection. Reset camera remains a separate toolbar button. |

Perspective and orthographic projection can be switched at any time. Wall scheme export always uses its own distortion-free orthographic renderer.

**Light**, immediately to the right of Overview, opens an active-level X-ray wiring view containing light points, light switches, their actual cable paths, and only the junctions, panels, or risers involved in those paths. Select a light point to pulse its controlling switches in red. The save control is icon-only: green means saved, the normal theme text colour means saving/unsaved, and red means local autosave failed.

After placing the first point of a wall, point the cursor in the intended direction, type its length in metres, and press `Enter`. Both `.` and `,` are accepted as decimal separators. A green target marks the snapped drawing position. `Backspace` edits the pending length; `Escape` or `Delete` cancels the unfinished wall.

While placing a wall, room boundary, or structure, hold `Shift` to temporarily bypass grid and wall snapping. Releasing `Shift` restores the project rules. Wall snapping projects the cursor to the closest point anywhere along an existing wall, including its endpoints and midpoint.

## Keyboard

| Shortcut | Action |
| --- | --- |
| `W` | Wall tool. |
| `D` | Device tool. |
| `R` | Room tool. |
| `T` | Structure tool, with Door opening selected initially. |
| `M` | Measurement tool. |
| `E` | Route tool. |
| `C` | Technical container tool. |
| `S` | Select tool. |
| `X` | Toggle X-ray mode. Walls become highly transparent while technical objects remain visible and selectable. |
| `Ctrl+S` | Save immediately. |
| `Ctrl+Z` | Undo. |
| `Ctrl+Shift+Z` or `Ctrl+Y` | Redo. |
| `Ctrl+C` / `Ctrl+V` | Copy and paste the current wall, device, or route selection. |
| `Ctrl+D` | Duplicate selection. |
| `Delete` or `Backspace` | Cancel the current drawing; in Select mode, delete the selection. |
| `Escape` | Cancel the current drawing, clear selection, and keep the active tool. |

Typing in a field suspends editor shortcuts. Common browser shortcuts retain their usual behavior outside the editor context. Right-click and right-drag control camera navigation throughout the viewport. Locking is controlled from the Properties panel.

In Normal view, walls, structures, and technical devices are selectable with left click; routes are display-only. Right click is reserved exclusively for orbiting. In X-ray view, technical devices and routes are selectable through transparent walls, while walls and wall-like structures do not intercept selection. Every visible route segment has a narrow, invisible 3D picking volume so vertical, floor, ceiling, and concealed wall runs respond consistently without making adjacent routes indistinguishable. While a wall-mounted type is active, the complete visible wall face accepts placement clicks. The pointer location becomes the mounting point and the device centre is offset only far enough for its configured BACK face to touch that exact wall face. There is no nearest-wall substitution. If the renderer reports the click on the floor plane, placement recovers a wall only when the pointer is inside that wall's physical footprint. Selecting a device type temporarily enables its service visibility so the new object cannot disappear behind an inactive filter.

Route creation starts by clicking a technical device and ends with one click on a different technical device. Every device click opens a compact two-column port chooser showing service-compatible free and occupied ports before the route can continue. The first endpoint may use input, output, or bidirectional. The second chooser enables only the coherent opposite direction (or bidirectional): output → input saves A → B, while input → output saves A ← B. Incoherent ports remain visible but disabled. The destination chooser stays open if route validation rejects the path and shows an inline alert naming the blocking device or structural rule; a successful concealed route reports its name and reminds the user to activate X-ray when needed. A free port can be used directly. If no service-compatible port exists, the same dialog shows the device's 3D model: click the exact connection position, enter its name/connector/direction/required face space, and choose **Save port and continue route**. Junction boxes and electrical panels are expandable: **Add another port** remains available and their schematic enclosure grows to reserve the accumulated termination space. Junction-box terminations are positioned inside its open-front schematic enclosure. To reuse an occupied physical port, first move its existing route to another compatible free port in the same dialog; otherwise the new connection is blocked. The route snaps to the chosen port's exact device-local position. Intermediate wall or plan clicks indicate the preferred path. The planner first calculates the shortest valid path across walls, floors, and ceilings. A compatible installed corridor is reused only when it remains within 5% of the shortest length, with an absolute maximum detour of 30 cm, and adds no more than one bend. The source and destination walls are excluded from corridor attraction, so a route first clears the device area and joins a common run farther along the structural path. Otherwise the route keeps its own direct path and may join an existing corridor only where that is naturally convenient. Compatible shared runs receive separate lateral lanes at the same installed height instead of being vertically stacked; a final segment-level pass also catches spans whose adjacent controls change only height. Intermediate controls are clamped inside every associated finished wall, while exact device-port endpoints remain untouched. Duplicate corner points are collapsed and lateral offsets use a single mitered point at a 90° wall junction. Before saving, the new route is checked against every route on the level and iteratively rerouted through the shortest clean lateral, vertical, or bounded orthogonal alternative. Floor crossings rise briefly toward the finished floor while remaining concealed; ceiling crossings step farther into the ceiling. Reapplying the floor service stack preserves these local crossing doglegs. If no bounded candidate can clear every conflict, the route remains visible, reports the unresolved count, and keeps the clash available for review. On connected walls, a route keeps the source port's height and changes height only near the destination, so a 1.3 m port can reach a 1.8 m port without dropping to the floor first. The complete floor and ceiling surfaces are valid routing planes at any X/Y coordinate; routes do not have to follow the wall perimeter while concealed in those planes. A riser-to-floor route changes height vertically inside the riser, then takes the shortest clean orthogonal path anywhere inside the floor. Ceiling-to-floor changes still use a valid wall, column, or riser for the vertical portion, while the horizontal portions may cross their full ceiling/floor planes. Except for the source and destination terminal approaches, every wall, floor, and ceiling run detours around a 10 cm expanded envelope surrounding installed devices and furniture. When tightly grouped equipment overlaps the selected endpoint's clearance zone, only the contiguous first/last terminal approach is exempt; middle route segments still enforce the full 10 cm clearance. Final route separation is discarded if it would violate that envelope. Same-wall segments also detour around the 10 cm door/window exclusion zone. Clicking a column while drawing adds it as an intermediate shaft. Select **Junction** in Route setup and click a route to split it into two connected branches, or place a standalone junction. **Floor transition** is also under Route setup; place it in X/Y and choose one adjacent level. Its body sits in the real ceiling/slab gap, is inset by the configured concealed ceiling offset, and exposes a shared floor interface to both levels at that same route elevation. Select the riser and pair each lower-floor route with its upper-floor continuation in **Cross-floor cable links**. A linked pair shares one physical sleeve lane; the continuity audit requires every route to be paired as well as directionally balanced. The actual riser has an invisible upper-floor interaction volume, so it can be selected from either adjacent level without drawing a fake penetration cap. Its cylinder expands from a minimum 18 cm diameter as physical lanes require more space. Select a route in X-ray to set flow direction and insert, edit, remove, or square exact intermediate turning points in Properties. Naming patterns and per-service prefixes are configured under **Settings → Route planning**.

**Ceiling route offset** is signed relative to the room ceiling plane: `−5 cm` places the route 5 cm inside/above the ceiling, `0 cm` places it on the plane, and `+5 cm` places it 5 cm below the ceiling. **Floor route offset** is entered as a positive burial depth and anchors the cable tier at 15 cm below the finished floor. **Settings → Route planning → Floor service stack** orders floor services from deepest upward. There is no separate tier-spacing value: each service's editable **Minimum side-by-side separation** is also used between its floor tier and the cable reference tier. Changing depth, order, or separation re-elevates existing below-floor runs while preserving local crossing doglegs. New conflicting routes are still checked against the complete level and resolved laterally or vertically before save.

When an older project is opened, concealed routes found crossing open room volume at an arbitrary height are repaired onto the valid endpoint floor or ceiling plane. This applies identically to every cable service as well as pipes and ducts, including wall-to-ceiling and wall-to-floor connections. Exact device endpoints are retained, terminal runs remain inside associated walls, and the floor/ceiling span is rebuilt as a short valid path.

Collision resolution classifies each segment by its actual structural surface. A mixed ceiling-to-wall or floor-to-wall route therefore remains on its selected plane after overlap avoidance. Surface normalization keeps wall lanes inside their associated walls and runs immediately before a newly created route is committed and autosaved.

All service categories and all three route kinds use the same clearance sequence. Coincident or closely parallel runs first receive separate side-by-side lanes. A floor or ceiling crossing receives a short dogleg deeper into that structural plane. Where a vertical route crosses a horizontal route inside a wall, it temporarily changes to another valid wall-depth layer and returns afterward. Collision proposals must remove the specific conflict being reviewed before path length is used as a tie-breaker. When projects open, routes are reconciled in persistence order so older installed runs remain stable and each later route clears them. A conflict remains in diagnostics when the configured physical envelopes exceed the available space, for example, two 160 mm ducts whose fixed device ports are only 120 mm apart.

Inside a wall, final saved route geometry is always normalized after planning and conflict resolution to wall-local horizontal and vertical runs; diagonal wall cuts are replaced with an orthogonal turning point. Concealed floor and ceiling planes also support diagonal runs when they provide the shorter valid path. Floor and ceiling turns are displayed with the service-specific **Turn curvature** bend radius from **Settings → Route planning**. At a floor/wall, ceiling/wall, or wall/wall structural transition, that radius is automatically clamped to the available drywall lining. The structural core provides a conservative fallback for walls with no lining, keeping the schematic bend concealed.

Only directed flows (`A → B` or `A ← B`) receive direction markers, and they are shown only while X-ray is active. Each route uses one stable set of evenly spaced markers moving at constant speed; only the marker reaching the endpoint wraps to the beginning, preventing duplicates, mid-route disappearance, and backward resets. Junction branches use the same fluent rule while preserving marker positions. Markers obey scene depth, so a device in front correctly hides them. **Settings → Drafting → Route direction motion** offers **Animated** and **Off**; Animated is the project default. Bidirectional and unspecified flows remain unmarked. Route point and device coordinate editors follow the drafting convention **X/Y = plan** and **Z = vertical**.

The Measurement tool offers **3D distance** and **Vertical height**. In either mode, clicking a device creates its height-from-floor annotation immediately; Vertical height also constrains two manually chosen points to one vertical line. Click either the measurement line or its value label to select it, then press `Canc`/`Delete` or `Backspace` to remove it.

The compact lower-right north arrow rotates with the camera; click it to align the camera north. A labelled X/Y/Z orientation gizmo in the lower-left follows the camera. **Top** first mounts the orthographic camera and then applies a true vertical plan view. Opening a project starts on its elevation-zero level, or the level nearest zero when none is exact. Editor and Photo sidebars number levels relative to elevation zero (`… −2, −1, 0, 1, 2 …`) and show each level name on its button. Selecting a floor isolates that level automatically. Use the pen in the **Active level** heading to add, edit, delete, and reorder levels, and to upload, calibrate, position, and toggle an image blueprint below the active drafting plane. The blueprint preview supports 50–400% zoom, an exact two-point scale line, a project 0,0 marker, one saved registration point per floor, and a two-point north arrow beside the alignment mode. Drawing the blueprint's north direction rotates the image toward project north while preserving its registration point. Status chips confirm saved scale, alignment, and north data after reopening. The pixel-to-project transform used by registration is the same transform used by the rendered underlay. Select the same physical point in each plan; plans with saved points automatically register to the elevation-zero plan when the project opens, when the point is placed, or when a reference floor is chosen. **Align points** remains available as an explicit reapply action. Later scale, north, or manual-rotation changes keep the registered world point fixed. **Full house** explicitly shows every floor at its true elevation with consistent wall styling. **Adjacent blueprint** and its lower/upper legend are inside **Levels & blueprints** and off by default; when enabled, the nearest lower floor is projected in blue and the nearest upper floor in amber onto the active working plane. Selecting a room from the list below **Services visibility** or in the viewport switches floors, isolates that room, and fits it with a small margin without changing Normal/X-ray or camera projection. Subsequent view changes retain the isolation; routes are clipped to the room plus exactly 1 m along each connected run beyond the boundary. Click empty space to leave room isolation. The detailed inventory remains available on **Overview**.

**Settings → Project diagnostics** combines route-clearance conflicts, cable runs longer than the 10 m target plus 1 m field tolerance, incomplete or imbalanced vertical risers, panel/junction correspondence errors, and technical devices with zero route attachments. Junction-box and electrical-panel Properties explicitly group one or more entering routes with one or more continuing exits; every connected route must occur in exactly one valid group. **Review** on a route conflict closes Settings, selects both affected routes in X-ray, centers the actual 3D camera on the clash, and marks it in red. **Show solution** replaces that solid marker with a wide, hollow green ring so the candidate remains visible through its centre. Cable, riser, panel/junction, and unconnected-device entries have **Locate** actions that switch to the correct floor and fit the object in the live model.

Select **Structure → Staircase**, click its start, Ctrl-click each intermediate corner, then click the final destination with a regular click to generate a lightweight staircase along that path. X-ray presents the individual translucent steps as a clear lightweight structure. **Structure → Furniture** opens a room-grouped standard furniture picker. Its rotatable 3D preview marks the selected mounting face as BACK and shows service-coloured connection points. In device, furniture, and rack previews, right-drag orbits, middle-drag pans, and the wheel zooms. In **Settings → Devices & furniture**, click a face and confirm it as BACK; that face is then kept in contact with the chosen wall, floor, or ceiling.

Every newly placed Rack is 800 mm wide, 1000 mm deep, and receives a prepared 22U editable layout containing a 2U UPS, PDU, NVR, individually modelled 48- and 24-port switches, paired 48- and 24-port front/rear patch panels, an empty cable U, and a shared 5U shelf containing separately selectable NAS, router, and mini-PC devices. Cabinet height follows its configured U capacity. **Settings → Devices & furniture** has separate **All other devices** and **Rack systems** workspaces. The installed list is displayed physically top-to-bottom, so U1 stays at the bottom. Selecting equipment opens exact front/back jack grids and per-port visible label, service, direction, speed, PoE, voltage, power, and media settings. **Patch panel** can add any numbered port count/row arrangement or a brush pass-through. Internal leads connect one equipment jack to another, patch-panel rear jacks expose normalized house-facing route endpoints, and every selected endpoint lists its connected route. The rotatable 3D rack uses black only for its four pillars, base, and top; the rack and its installed equipment remain opaque in X-ray so individual units stay legible.

Edits to a built-in definition under **Settings → Devices & furniture** are application-wide local defaults: its dimensions, schematic appearance, association, mounting back, and default ports are overlaid when any project is opened or created. Custom device types and installed device instances remain owned by their project. Deleting an installed device also deletes every route attached to either of its endpoint ports and cleans riser, junction/panel, and lighting references.

Technical-device and structural-object Properties use three compact rows: X/Y/Z, width/height/depth, and rotation Z/distance from floor/**Depth from wall**. The last value is the BACK-face recess measured inward from the finished outer wall surface, including drywall. Door openings default with their lower edge on the floor; window centres default to Z = 170 cm. Wall Properties separately edit structural-core and left/right lining thicknesses; the finished total is derived. Left/right are defined while looking from the wall's first point toward its second point. Concealed routes are anchored to the matching lining centreline instead of the core. Mounting-face and port authoring is intentionally centralized in **Settings → Devices & furniture** and the no-compatible-port route workflow.

Settings descriptions appear as custom hover help on headings, fields, selectors, and values, keeping the panels compact while preserving explanations.

The camera button at the upper-right of the viewport captures the current scene in light mode and opens an A4 landscape, 5× low-ink PNG preview. **Overview**, beside the project title, opens interactive whole-house MEP totals and service/floor/route reports. Its detail buttons open the asset inventory or rooms/zones. The dedicated **Light** view derives documented lighting topology from installed route endpoints and explicit junction/panel correspondence or paired riser continuity. Operational control remains with the installed building systems.

**Photo**, immediately to the left of Settings, opens a documentation view with route-motion arrows disabled. Choose a numbered level or Full house, filter marker categories from the compact left panel, and use the single header X-ray toggle; Normal hides technical routes. Choose **Add photo point**, click the exact model location, then name and categorize it in the small creation popup. The yellow camera marker opens all JPEG/PNG/WebP images attached there. Image bytes remain in the matching `.data/projects/<project-id>/assets/photos/` folder.

Editing a door or window opening's X/Y/Z coordinates reprojects the opening onto its associated wall and immediately refreshes the wall cut. Connected rendered walls use deterministic non-overlapping butt joints at branches and corners, while their editable wall records remain independent.

Route Properties combine endpoint and flow controls in a compact A/B strip. Hover A or B to inspect its assigned connection port, and click the centre arrow to cycle A → B, A ← B, bidirectional, and no-flow states. Route installation status/date and notes follow the same installation controls used by devices; test state remains documented separately.

The A/B strip sits inside the route's primary Properties section immediately before calculated length. Cable Properties omit the generic Standard field. Pipe diameters share one row, and duct width, height, and diameter share one row.

**Settings → Route planning** uses one category-parameter switcher for minimum separation, turn curvature, and default installed diameter. Only the selected values are shown. Explicit cable-conduit, pipe external, or duct dimensions override the category default; otherwise the default diameter is rendered in real-world scale in the 3D viewport. Route conflict checks use the greater of configured centreline separation and the two routes' physical radii, keeping large duct envelopes separate even when their service separation is smaller. The Rooms list always follows the active numbered floor, even while Full house is displayed. Full house remains a separate scope toggle but is visually grouped with the level buttons.

Routes with an installed diameter of 4 cm or less retain the lightweight drafting line. Routes larger than 4 cm are rendered as true cylindrical 3D geometry using their exact installed diameter and service colour; non-solid service patterns remain visibly dashed along the tube. This change affects rendering only; route coordinates, length, snapping, selection, and collision calculations keep their existing behavior.
